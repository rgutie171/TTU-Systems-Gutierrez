This project develops mixed-integer optimization models for scheduling the 2026–27 UEFA Champions League league phase. Using the fixed 144-match draw across eight matchdays, the models minimize home/away breaks while enforcing that every club plays once per matchday, has four home and four away matches, avoids three consecutive home or away matches, and respects national-federation restrictions. A separate variant adds strict city-pair rules requiring paired clubs such as Real Madrid and Atlético de Madrid to avoid hosting on the same matchday. Gurobi was used with warm starts and one-hour time limits to compare the original 48-break calendar with improved feasible schedules, including a 40-break result for the federation model and a 36-break incumbent for the strict-city variant.
